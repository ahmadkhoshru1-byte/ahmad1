ساخت فایل APK از چک‌لیست بهداشت حرفه‌ای ۱۴۰۵
==============================================

پیش‌نیاز (یک‌بار نصب شود، روی ویندوز/مک/لینوکس):
  1) Node.js  (نسخه 20 یا بالاتر)
  2) Android Studio  (همراه با Android SDK)

مراحل:
  1) پوشهٔ داخل zip را باز کنید و در همان پوشه ترمینال (CMD) بزنید:
         npm install
         npx cap sync android
  2) Android Studio را باز کنید:  Open  ←  پوشهٔ android
  3) صبر کنید Gradle همگام‌سازی شود (بار اول چند دقیقه طول می‌کشد).
  4) منوی  Build ← Build Bundle(s) / APK(s) ← Build APK(s)
  5) فایل خروجی:
         android/app/build/outputs/apk/debug/app-debug.apk
     آن را به گوشی بفرستید و نصب کنید (اجازهٔ «نصب از منبع ناشناس» لازم است).

برای تغییر محتوا: فایل  www/index.html  را جایگزین کنید و دوباره
         npx cap sync android
را بزنید و APK را مجدداً بسازید.

نکته: ذخیرهٔ اطلاعات در حافظهٔ داخلی برنامه روی همان گوشی انجام می‌شود.
دکمه‌های «اکسل» و «پشتیبان» که فایل دانلود می‌کنند ممکن است داخل برنامه کار نکنند
و نیاز به افزونهٔ ذخیرهٔ فایل دارند.
